# Proposed outline: „מאחורי הפלייליסט" (Behind the Playlist)

*Status: **approved** v1.0 · 2026-11-14 (Prompt 9): Noa approved, 20-page plan approved, diagram stays in Ch. 6. Cover details stay as marked placeholders.*
*Sources below were the pre-research candidates. Verified results: `docs/agents/research-notes.md` and `book/references.bib` (R1, 2026-11-14). Sources listed below are **candidates** from the Boss's own knowledge, not yet verified. The Researcher agent must open and confirm each one (or replace it) before the Writer uses it.*

## Frame

- **Format:** A4, 20 pages, XeLaTeX. Each chapter is about 2 pages.
- **Fictional listener:** **נועה** (Noa), 24, a student in Tel Aviv. She has a phone, a premium subscription to an unnamed streaming app, and strong opinions about 2000s pop. All her data is invented and labelled so.
- **Running structure of each chapter:**
  1. **Scene** (½ page): a short, humorous moment from Noa's day.
  2. **Explanation** (1–1½ pages): one mechanism, plain Hebrew, with citations.
  3. **„בקצרה"** box: 2–3 takeaways.
- **Box types** (defined once in `style.sty`):

  | Box | Purpose |
  |---|---|
  | „בקצרה" | Key takeaways (brand color) |
  | „מעבדה" | Formula or worked example (secondary color) |
  | „רגע, זה אמיתי?" | Myth vs. research, or what a company has *publicly* said (accent color) |
  | „נתונים בדיוניים" | Small grey tag on every fictional table, graph or number |

## Proposed agent flow (about 5 calls)

1. **Researcher ×1:** verify or replace the candidates above, then write `research-notes.md` (claim → source per chapter) and `references.bib`.
2. **Writer ×2:** call A writes Ch. 1–4 and the abstract; call B writes Ch. 5–8.
3. **Boss:** style file, cover, graph, table styling, diagram, build, render.
4. **Reviewer ×2:** call A checks text and facts against the notes; call B checks the rendered PDF pages against PRD §8.
5. Fix round by the Boss and/or one extra Writer call only if the Reviewer requests changes.
